# Cuestionario SUS (System Usability Scale; Brooke, 1996), adaptación al español

Escala de 1 (totalmente en desacuerdo) a 5 (totalmente de acuerdo).

1. Creo que me gustaría usar este sistema con frecuencia.
2. Encontré el sistema innecesariamente complejo.
3. Pensé que el sistema era fácil de usar.
4. Creo que necesitaría el apoyo de una persona técnica para poder usar este sistema.
5. Encontré que las distintas funciones del sistema estaban bien integradas.
6. Pensé que había demasiada inconsistencia en el sistema.
7. Imagino que la mayoría de las personas aprendería a usar este sistema muy rápido.
8. Encontré el sistema muy engorroso de usar.
9. Me sentí muy seguro(a) usando el sistema.
10. Necesité aprender muchas cosas antes de poder empezar a usar este sistema.

## Puntaje
- Ítems impares: respuesta − 1.
- Ítems pares: 5 − respuesta.
- Suma × 2,5 = puntaje de 0 a 100.
- Referencia: 68 es el promedio. Si se cita esa referencia en el documento, hay que buscar la fuente académica con DOI (no se cita de memoria).

Cita del instrumento en el documento: Brooke (1996), capítulo de libro. Verifica la referencia completa antes de incluirla.
